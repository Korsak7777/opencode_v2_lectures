# OpenCode V2 — цикл концептуальных заметок

Цикл из семи заметок об open-source AI-кодинг агенте [OpenCode V2](https://opencode.ai/v2/docs/) — для инженеров, которые уже знают OpenCode v1 или другие агенты (Claude Code, Codex CLI). Фокус — отличия V2 и миграция, азы не разбираются.

Заметки написаны в стиле концептуального Zettelkasten: рамки и метафоры, сравнительные таблицы, ASCII-схемы, примеры — но без пошаговых инструкций и простыней конфигов. Факты — из официальной документации V2 (ссылки в тексте), вторичные источники и собственные выводы помечены явно (`[код, не доки]`, `[вывод]`).

Для заметок 03–08 есть HTML-версии (`.html`) — те же тексты, свёрстанные для чтения вне markdown-редактора.

## Как читать

- **Последовательно (02 → 08)** — как доклад: заметки связаны сквозным сюжетом и ссылаются друг на друга.
- **Выборочно** — каждая заметка самодостаточна: открывает свой мини-глоссарий и не требует предыдущих.
- **По тегам** — файлы помечены `#opencode`, `#ai-agents`, `#AI_gen`, `#git`.
